# ADR-011: Merkle anti-entropy over the partitioned fact set with additive digests and pull-based repair

## Status
Accepted

## Context
Replication can lose or delay writes; restored backups and re-imports must
converge; verifying "both regions hold the same facts" must not read the
whole set.

## Decision
- Per partition and per region, a 3-level 16-ary hash-prefix trie over
  `fact_id` with LtHash-style additive digests (sum of 16-bit lanes of
  SHA-256(fact_id)) so an insert updates O(depth) nodes without reading
  siblings.
- Leaves hold member pointers `(fact_id, PK, SK)` so repair needs no index.
- Hourly per active partition: compare roots; descend on mismatch; pull
  missing facts from the peer by pointer; unconditional identical-content
  put locally. Repair never deletes.
- XOR digests are rejected: an adversarial writer could craft colliding
  sets; additive lattice hashes resist this.

## Consequences
- ~$2/month at L10k; scales with active partitions.
- Repair re-enters the stream and folds normally; idempotency is essential.
- Shredded facts (ADM-12) must be skipped by repair when the local copy is
  shredded.

## Alternatives rejected
- Full-scan reconciliation: O(N) reads per run.
- Relying on Global Tables replication alone: no verification, no recovery
  path for restores.
